# SeansLifeArchive

This is the root of the Seanpm2001 (Sean Patrick Myrick) Life Archive project. It is strongly recommended to start at the [:octocat: `sleeve`](https://github.com/seanpm2001/SeansLifeArchive_Sleeve/)

## Major divisions

There are currently 4 major divisions listed.

### SeansLifeArchive_Daily-articles

> [:octocat: `SeansLifeArchive Daily Articles`](https://github.com/seanpm2001/SeansLifeArchive_Daily-articles/)

The core of the journal, contains the continuous daily document series started on 2016, September 27th.

### SeansLifeArchive_Images

> [:octocat: `SeansLifeArchive Images`](https://github.com/seanpm2001/SeansLifeArchive_Images/)

A collection of Git-image repositories for pictures that are related to the life archive project.

### SeansLifeArchive_Maps

> [:octocat: `SeansLifeArchive Maps`](https://github.com/seanpm2001/SeansLifeArchive_Maps/)

A collection of cartography repositories for map data that is related to the life archive project.

### SeansLifeArchive_Extras

> [:octocat: `SeansLifeArchive Extras`](https://github.com/seanpm2001/SeansLifeArchive_Extras/)

Contains extra content that isn't in the other categories, and still relates to the life archive project.
